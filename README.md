### About

I build **production mobile applications** with React Native, with a focus on
maintainable architecture and a polished user experience.

My work covers the full delivery cycle: layered application architecture,
typed state management, Firebase-backed auth and data, native Android/iOS
integration, and shipping to the app stores — including the release,
versioning, and privacy-compliance work (KVKK / GDPR) that comes with it.

I care about code that the next developer can read, and interfaces that the
user never has to think about.
